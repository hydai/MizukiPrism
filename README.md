# MizukiPrism

Song catalog and player for VTuber 浠Mizuki's karaoke livestream archive — browse songs, watch timestamped VOD clips, and follow along with synced lyrics.

## Features

- **Song Catalog** — searchable, sortable song list with album art thumbnails and virtual scrolling for fast rendering
- **Timestamped Playback** — play any performance directly from the VOD at the exact timestamp
- **Streams Timeline** — browse karaoke livestream archive (歌枠回放) with per-stream song lists
- **Mini Player & Queue** — persistent playback controls with drag-and-drop queue management
- **Synced Lyrics** — karaoke-style lyrics that scroll with playback (powered by LRCLIB)
- **Album Art** — cover images from iTunes/Deezer displayed across all UI positions
- **Fan Playlists** — create and manage personal playlists, liked songs, and recently played (stored locally)
- **Mobile-Optimized** — responsive design with bottom navigation, mobile search, and iOS Safari compatibility
- **Admin Staging** — curator dashboard with D1 database for reviewing, editing, and approving songs/streams before publish
- **MizukiLens CLI** — data pipeline tool for curators to manage the song catalog, metadata, and admin database

## Getting Started

### Prerequisites

- Node.js 20+
- Python 3.10+ (for MizukiLens CLI)

### Frontend

```bash
npm install
npm run dev        # http://localhost:3000
```

### MizukiLens CLI

```bash
cd tools/mizukilens
python3 -m venv .venv
.venv/bin/pip install -e .
mizukilens --help
```

## Data Pipeline

Song data flows through a curator-managed pipeline:

```
YouTube VODs → MizukiLens CLI → data/*.json → git commit → GitHub Pages → Fans
                    ↕
              Admin D1 DB → Workers API → Curator Dashboard
```

1. **Discover** — `mizukilens fetch` scrapes YouTube for new livestream VODs
2. **Extract** — `mizukilens extract` pulls song timestamps from comments/descriptions
3. **Review** — `mizukilens review` opens a TUI for curators to verify and edit
4. **Export/Import** — `mizukilens eximport` roundtrips data between cache and `data/songs.json`
5. **Metadata** — `mizukilens metadata fetch` enriches songs with album art from iTunes
6. **Standardize** — `mizukilens candidates` manages song name standardization across performances
7. **Admin Staging** — `mizukilens db export` syncs approved data to the D1 staging database
8. **Stamp Editor** — admin UI with interactive timestamp editor, iTunes duration lookup, and batch approval

## Admin Dashboard

The curator admin system runs on Cloudflare Workers with a D1 database:

```bash
cd admin
npx wrangler dev             # Local dev server
npx wrangler deploy          # Deploy to production
npx wrangler d1 execute mizukiprism-staging --file=schema.sql  # Init DB
```

Admin pages: Dashboard, Streams List, Songs List, Song Detail, Stamp Editor, Submit Song/Stream.
